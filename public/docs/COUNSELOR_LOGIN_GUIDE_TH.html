สำหรับเจ้าหน้าที่ให้คำปรึกษา (Counselor) แยกตามสาขา — testD x SWING

🖨️ พิมพ์ / บันทึกเป็น PDF

1. สิ่งที่ต้องมีก่อนเริ่มใช้งาน

  • บัญชีเจ้าหน้าที่ ที่ผู้ดูแลระบบ (Admin) สร้างให้ พร้อม ระบุสาขา ของคุณแล้ว
  • ชื่อผู้ใช้ (Username) และ รหัสผ่าน ที่ได้รับ (รหัสผ่านอย่างน้อย 8 ตัวอักษร)
  • อินเทอร์เน็ต + เบราว์เซอร์ Chrome / Safari (ใช้บนมือถือได้)

บัญชีเจ้าหน้าที่ภายในไม่ต้องใช้อีเมลจริง ระบบจะเติม @swingth.local ให้อัตโนมัติ

2. ขั้นตอนการเข้าสู่ระบบ

  1. เปิดเว็บไซต์ https://testd.website/auth
  2. กรอก ชื่อผู้ใช้ ในช่องแรก (พิมพ์เฉพาะชื่อผู้ใช้ เช่น silom.counselor1 — ไม่ต้องพิมพ์ @swingth.local)
  3. กรอก รหัสผ่าน แล้วกดปุ่มเข้าสู่ระบบ
  4. เมื่อเข้าสำเร็จ ให้เปิดเมนูหลังบ้านที่ https://testd.website/admin
  5. ระบบจะแสดงเฉพาะเมนูและข้อมูลของสาขาที่คุณสังกัดเท่านั้น
เข้าไม่ได้? ตรวจสอบตามลำดับ: พิมพ์ชื่อผู้ใช้/รหัสผ่านถูกต้องหรือไม่ → บัญชีถูกตั้งเป็น “ปิดใช้งาน” หรือไม่ (ระบบจะบังคับออกจากระบบทันที) → แจ้งผู้ดูแลระบบเพื่อรีเซ็ตรหัสผ่าน หรือเปิดใช้งานบัญชีใหม่

3. เมนูที่เจ้าหน้าที่ให้คำปรึกษาเข้าถึงได้

เมนูใช้ทำอะไร
ศูนย์ให้คำปรึกษา (Counselor Support)ดูรายการเคสที่ต้องติดตาม บันทึกการให้คำปรึกษา และดูข้อมูล Harm Reduction ที่ผู้รับบริการยินยอมให้เห็น
สรุปรายวันของสาขา (Daily Branch Brief)ภาพรวมนัดหมายวันนี้ เวลาที่จองเข้ามา สถานะคิว และเคสเร่งด่วนที่ถูกไฮไลท์
สรุปเรื่องที่กังวลรายวัน (Concern Brief)ดูหัวข้อที่ผู้รับบริการเลือกไว้ก่อนเข้าคิว และคะแนนคัดกรอง PHQ-4 เพื่อเตรียมตัวก่อนคุย
กระดานคิว (Queue Board)ติดตามคิวแบบเรียลไทม์ เรียกคิว และอัปเดตสถานะการรับบริการ

หากต้องการเมนูเพิ่ม (เช่น รายงานผลชุดตรวจ หรือการเงิน) ต้องให้ผู้ดูแลระบบกำหนดสิทธิ์เพิ่มเติม

4. การแยกข้อมูลตามสาขา

  • บัญชีของคุณผูกกับสาขาเดียว (เช่น สีลม, พัทยา, สะพานควาย, เพชรเกษม, อุดมสุข)
  • รายการนัดหมาย คิว และเคส จะกรองให้อัตโนมัติเฉพาะสาขาของคุณ
  • ต้องการดูข้ามสาขา ให้ประสานผู้ดูแลระบบ — ห้ามใช้บัญชีของเพื่อนร่วมงาน

5. ขั้นตอนการทำงานประจำวัน (แนะนำ)

  1. ก่อนเปิดบริการ — เปิด “สรุปรายวันของสาขา” ดูจำนวนนัดหมายและเวลาที่จองเข้ามา
  2. ก่อนเรียกคิว — เปิด “สรุปเรื่องที่กังวลรายวัน” ดูหัวข้อที่ผู้รับบริการกังวล และเคสที่มีคะแนน PHQ-4 ≥ 3
  3. ระหว่างให้บริการ — อัปเดตสถานะคิวทุกครั้ง (เรียกคิว / กำลังให้บริการ / เสร็จสิ้น)
  4. หลังให้คำปรึกษา — บันทึกโน้ตเคสและการส่งต่อใน “ศูนย์ให้คำปรึกษา” ภายในวันเดียวกัน
  5. ก่อนปิดบริการ — ตรวจว่าไม่มีเคสค้างสถานะ และออกจากระบบทุกครั้ง

6. ความปลอดภัยและ PDPA

  • ข้อมูลส่วนบุคคลถูก ปิดบัง (masked) ไว้ตั้งแต่ต้น ต้องกด “เปิดเผยข้อมูล” เฉพาะเมื่อจำเป็น — ทุกครั้งจะถูกบันทึกลง audit log
  • ระบบจะ ออกจากระบบอัตโนมัติ เมื่อไม่มีการใช้งานต่อเนื่อง
  • ห้ามแชร์บัญชี ห้ามถ่ายภาพหน้าจอที่มีข้อมูลผู้รับบริการ และห้ามส่งข้อมูลผ่านแชตส่วนตัว
  • การส่งออกไฟล์ CSV จะมีลายน้ำระบุตัวผู้ส่งออกฝังอยู่ในไฟล์
  • ใช้อุปกรณ์ของหน่วยงาน หรือหากใช้เครื่องส่วนตัวให้ล็อกหน้าจอและออกจากระบบทุกครั้ง

7. ปัญหาที่พบบ่อย

อาการวิธีแก้
เข้าสู่ระบบแล้วแต่ไม่เห็นเมนู /adminบัญชียังไม่ได้รับสิทธิ์ counselor — แจ้งผู้ดูแลระบบ
ถูกเด้งออกทันทีหลังล็อกอินบัญชีถูกตั้งเป็น “ไม่ใช้งาน” ในระบบ ให้แจ้งผู้ดูแลเปิดใช้งาน
ไม่เห็นเคสของสาขาตัวเองบัญชียังไม่ได้ผูกสาขา หรือผูกผิดสาขา — แจ้งผู้ดูแลระบบตรวจสอบ
ลืมรหัสผ่านบัญชีภายในรีเซ็ตเองไม่ได้ ต้องให้ผู้ดูแลระบบตั้งรหัสผ่านใหม่ให้
หน้าจอค้าง/ข้อมูลไม่อัปเดตรีเฟรชหน้าเว็บ (ดึงหน้าจอลงบนมือถือ) หรือปิดแล้วเปิดเบราว์เซอร์ใหม่

8. สำหรับผู้ดูแลระบบ: การสร้างบัญชีให้เจ้าหน้าที่รายสาขา

  1. เข้า /admin → กลุ่มเมนู “จัดการระบบ” → บัญชีเจ้าหน้าที่ให้คำปรึกษา
  2. กด “เพิ่มบัญชี” แล้วกรอกชื่อผู้ใช้ ชื่อที่แสดง รหัสผ่านเริ่มต้น และเลือกสาขา
  3. บันทึก แล้วส่งชื่อผู้ใช้/รหัสผ่านให้เจ้าหน้าที่ผ่านช่องทางที่ปลอดภัย และแจ้งให้เปลี่ยนรหัสผ่านทันที
  4. เมื่อเจ้าหน้าที่ลาออกหรือย้ายสาขา ให้ปิดใช้งานบัญชี หรือแก้สาขาในหน้าเดียวกัน
